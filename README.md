# DangoCubedSite
The official website of the Dango³🍡 group

## Local Icons

Font Awesome Free 6.7.2 is self-hosted in `fontawesome/`. Only the core,
Brands, and Solid CSS and the two corresponding WOFF2 fonts are included.
The style files omit the unused TTF fallback URLs; upstream attribution
comments and `fontawesome/LICENSE.txt` are retained. The files come from
the `@fortawesome/fontawesome-free@6.7.2` npm package.
